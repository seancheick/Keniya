# Recent changes audit — October 15, 2026

Reviewed local HEAD `51a99e5`, the storefront/offer/Monthly Snack Club revamp (`8d3238b`), and the preceding six commits covering catalog evidence, clinician review, lineup warnings and example photography. Inspected recent commerce changes and ran the existing rules, clinical, packing and database suites. This is not an independent clinical literature review or a production deployment certification.

## Fixes

- **Renewal dietary instructions:** renewal invoices do not carry checkout custom fields. `save_renewal_order` now inherits avoid instructions and snack preference from the admitted first subscription order. A new migration is registered in the migration runner. The new SQL regression failed before the fix and passes afterward.
- **Out-of-order billing events:** subscription change events now retrieve current Stripe state rather than copying the event's older snapshot into the local mirror. Regression covers an old active event delivered after cancellation. This does not provide transaction-level fencing across simultaneous Stripe reads and local writes.
- **Lost lifecycle emails:** failed renewal/reminder/hold/cancellation sends now fail the webhook for retry rather than being acknowledged as delivered.
- **Cancellation failure handling:** a Stripe retrieval failure now returns the action's retryable error message rather than escaping its error handler.
- **Wrong payment on checkout replay:** the first order uses its checkout session's invoice, not the subscription's changing latest invoice.
- **Address rollback on replay:** duplicate checkout delivery preserves the subscriber's current shipping address and email while refreshing billing fields.
- **Unrelated invoices:** Club invoice handlers ignore subscriptions without Keniya box metadata, avoiding accidental invoice voids, order creation or emails for other products.
- **Offer display:** the purchase panel takes discount price/code from current server settings, not a potentially stale browser claim.
- **Skip copy:** the management page describes the actual resume date for multi-month skips rather than always claiming renewal resumes the following month.
